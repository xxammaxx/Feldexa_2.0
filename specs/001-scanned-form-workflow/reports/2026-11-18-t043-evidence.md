  `ChangeNotifier`; the selected control is kept inside the horizontal strip,

  previous/next buttons labelled from German `MaterialLocalizations`

### Widget behaviour

- **Page order and state.** `PageStrip.pages` is one entry per viewer page, in
  original document order. The list position is the zero-based index; the UI
  shows `index + 1`. `PageStripPage.analysisState` is one of `pending`,
  `analyzing`, `ready`, or `failed`; `unreadable` and `uncertain` are
  independent flags. A failed page stays tappable.
- **Navigation and selection.** `PageStripController.selectPage(index)` calls
  `viewer.scrollToPage(index)` and then updates the selected index. Selecting
  the same page still asks the viewer to show it but does not notify. Previous
  and next no-op at the document boundaries; an out-of-range explicit selection
  throws `RangeError`. A selection can be made before the viewer has a
  viewport; the viewer call is then its documented no-op.
- **Responsive layout.** A `LayoutBuilder` measures the region width; widths
  strictly below `600` dp use the compact indicator, and exactly `600` dp uses
  the full horizontal strip. No `MediaQuery` screen width overrides a bounded
  parent. The compact previous/next labels come from
  `MaterialLocalizations.previousPageTooltip`/`nextPageTooltip`, which resolve
  to „Vorherige Seite“/„Nächste Seite“ in German.
- **Long documents.** The full strip is a horizontal `ListView.builder` with a
  fixed `112`-dp item extent. Initial page 0 builds fewer than 20 controls out
  of 100; selecting page 100 jumps the scroll offset arithmetically and builds
  the last controls without building all 100.
- **Accessibility.** Page controls expose
  `label = a11yPageNavigation(page, count)` („Seite X von N“), a German state
  hint, `button`, `selected`, and a tap action. The compact indicator exposes a
  live-region label and hint and is not a button. Compact buttons expose
  `button`, `enabled`, a German label, and a tap action when enabled. State is
  also visible as a distinct icon plus text, so it is not colour-only;
  selection adds a thicker outline and a 4-dp top bar. Text height grows with
  the system text scale, and the 200 % test completes without overflow.
- **Text provenance.** „Seite X von N“ comes from the committed
  `a11yPageNavigation` ARB message. „Nicht lesbar“ comes from the committed
  `statusUnreadable` message. The uncertainty word comes from
  `a11yFieldUncertain` with its documented leading `, ` suffix removed. The
  previous/next labels come from German `MaterialLocalizations`. The four
  analysis-state hints and four short visible state words are local German
  presentation vocabulary because the catalog has no per-page analysis-state
  row; no ARB key or catalog row was added.
- **Privacy and immutability.** The widget reads only its `pages` argument and
  the viewer's page count/selection seam. It creates no file, cache, temporary
  object, image, network request, or log entry. It does not render or
  reconstruct a source page.
