## Screenshot phases

The five screenshots are five distinct captures with five distinct SHA-256
values (recorded in `screenshot-hashes.txt`). Each phase asserts its state
before the marker is emitted, and the driver deletes a stale acknowledgement
before waiting for a fresh one:

- `overlay-selection`: a selected confirmed field is visible on the settled
  editor and no value sheet is present.
- `value-sheet`: the sheet is settled with the German value entered and the
  real IME visible; the sheet, input, and save action are asserted above the
  keyboard before the capture.
- `saved-status`: the sheet is reopened immediately after the verified save,
  prefilled from the store read-back; the T091 saved label is in the app bar
  behind it. It is not a bare editor and not a duplicate of
  `overlay-selection`.
- `document-list`: the start list after leaving the editor.
- `reopened-value`: the reopened document's sheet prefilled from the reopened
  store read-back.

## Evidence byte integrity

The repository copy of `device-identity.txt` is 298 bytes; the driver original
`/tmp/t071a-fix4-run/device-identity.txt` is 300 bytes. They differ only by
trailing spaces stripped from the `wm_size` and `wm_density` lines; all values
are identical. The repository copy of `integration-android-t071a.log` is 3968
bytes; the driver original `/tmp/t071a-fix4-run/integration-android-t071a.log`
is 3994 bytes. They differ only by trailing spaces stripped from one Gradle
progress line; all log content is identical. `correction-4-host-gates.txt` is
the 140937-byte repository copy of the 140977-byte handover original, differing
only by stripped trailing padding on one `flutter analyze` line; every command,
result, and exit code is identical. The hashes in the parent report and
`screenshot-hashes.txt` are for the repository copies, not the unstripped
originals.

## Marker and logcat limitation

T071A markers are emitted by the integration test process on the host side,
not by the app process. Device logcat therefore cannot contain them;
`logcat-t071a-markers.log` contains only Android lifecycle lines.
`markers-integration.txt` (57 lines) is the authoritative marker sequence, and
`integration-android-t071a.log` is the underlying integration-test log. The
driver's `marker-sequence.txt` records the five screenshot handshakes and the
final PASS line.
