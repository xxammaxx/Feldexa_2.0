### Failure-class message accuracy

protection, typed and raw canonical unsupported encryption, unreadable,
truncated, missing, not a PDF, unsupported structure, unknown reason, too
large, an unmapped code, `IMP-000`, `PLT-004`, storage full, aggregate key

The catalog test independently parses the committed Markdown rows in §1 and §3

### FR-007 truthfulness

`import.rejected.passwordProtected` diagnosis, whose text contains
„passwortgeschützt“. Every other case, including both canonical
unsupported-encryption paths, `IMP-005`, `IMP-002`/`IMP-003`/`IMP-004`,

FR-007 and does not change production behaviour.

### FR-094 privacy and readable errors

is present wherever the catalog defines it. For each rendered message and
recovery, the test rejects catalog-code patterns, the literal `IMP-`, `SAVE-`,

`toString` values are checked against the same rules; they expose only
severity/retry/cancel flags, page numbers, or page counts, never codes, text,

`isUnrecognized == true`, a false password flag, and no creation.
