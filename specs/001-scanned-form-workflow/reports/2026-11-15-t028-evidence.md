`packages/feldexa_adapters_simulated/lib/` for document import, page
rasterization, OCR, secure storage, PDF export, and delivery. It does not

## 6. Determinism

- The adapters never read `DateTime.now()`, `Stopwatch`, `Random`, the file
  system, or the network. One `SimulatedAdapterContext` supplies a fixed UTC
  instant and a monotonic UUIDv4 sequence; two fresh contexts produce identical
  ids and timestamps.
- Rasters are derived from the request and a SHA-256 marker; identical requests
  return identical bytes, different pages differ.
- The `pdf` package stamps a random document ID. The adapter replaces that one
  trailer token with a SHA-256 of the canonical plan and refuses to return
  bytes when the expected trailer shape or a date field is absent; two exports
  of the same plan were byte-identical in the host suite.
- The host source scan asserts the absence of time/randomness reads from
  `lib/`.

## 7. Limitations and non-claims

- **No Android evidence.** This report contains no `EMULATOR` or `DEVICE` run,
  no SAF behavior, no ML Kit OCR, no Android Keystore, no PDFBox, and no APK.
- **No encryption claim.** The simulated store is an in-memory substitute. It
  preserves observable port semantics but provides no confidentiality,
  integrity, Keystore, or durability guarantee.
- **No independent artifact verification.** The preview export records the
  canonical `ArtifactVerification` booleans from simulated self-checks; it does
  not run `qpdf`, Poppler, MuPDF, PDFBox, or an independent renderer, and it
  must not be used for SC-005/SC-006 or any Android acceptance claim.
- **Error-code representation.** `contracts/ports.md` §3 makes only
  `ExportBlockedException` (`EXP-001`) and `ExportFailedException` (`EXP-002`)
  typed classes; catalog-only `EXP-003`–`EXP-006` are carried by the
  `validate` operation result. `export` therefore keeps the correct canonical
  exception class for the observed failure while `validate` remains the exact
  code surface; it no longer collapses a source/page failure into a
  field-level block or vice versa.
- **FR-086 is not complete.** The Chrome test covers the six adapters over the
  committed fixture catalogue only; it is not the browser editor journey. The
  user-visible FR-086 journey remains T128 and is still open.
- **Font substitution.** Without caller-supplied Noto Sans bytes the preview
  uses the PDF standard Helvetica substitute; text outside Latin-1 blocks with
  `EXP-004` rather than silently drawing a substitute glyph. The Web bootstrap
  should pass the bundled font for production-parity preview text.
- **Source-page fidelity.** The preview uses a clearly labelled placeholder
  unless the caller supplies pre-rasterized page images through
  `pageImageProvider`; this package deliberately does not depend on `pdfrx`.
- **No performance claim.** No timing or throughput measurement was made.
- **No product-requirement change.** The provisional OD-1 exclusion behavior is
  inherited from `contracts/export-plan.md`; T028 does not settle it.
- No push, merge, self-review, or pull request was performed.
