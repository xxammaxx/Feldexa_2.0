## 1. Scope

This report covers **T032 / #32 only**: the machine-readable evidence-report
schema `tools/evaluation/report_schema.json` and the full validator
`tools/evaluation/validate_report.dart`, together with its host regression
suite `tools/evaluation/validate_report_test.dart`. It implements constitution
Principle VIII's evidence separation, honest status, conditioned performance
claims, artifact integrity, and privacy rules for the report template; it does
not implement any later task.

The evidence class is `NONE` because every check is a static/host check. This
report cannot prove runtime behavior, OCR quality, storage/encryption, export
validity, or device performance.

The built-in `checklists/requirements.md` is fully checked (16/16). The custom
`checklists/precision-testability.md` has 36 intentionally unchecked
reviewer-owned requirements-quality items; its companion assessment directs
`speckit-implement` not to mark them. This report claims no checklist or
reviewer approval. `.specify/extensions.yml` declares `hooks: {}`, so no
`before_implement` or `after_implement` hook was registered or executed.
