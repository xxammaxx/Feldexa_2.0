## 5. Results

Corpus: 10 synthetic A4 pages, 33 declared fields. "Baseline" is every typed
geometry candidate the productive pipeline would propose today; "inventory" is
the new deduplicated, role-classified candidate set. Both are compared with the
same declared ground truth under strict matching (`IoU >= 0.5` and identical
type).

| Metric | Baseline | Inventory |
| --- | ---: | ---: |
| matched | 28 | 28 |
| extra | 7 | 6 |
| duplicate (unmatched) | 6 (5) | 6 (5) |
| precision | 0.700 | 0.718 |
| recall | 0.848 | 0.848 |
| F1 | 0.767 | 0.778 |
| type accuracy | 0.821 | **1.000** |
| label accuracy | 0.813 | 0.813 |

Declared no-regression gate (`inventory matched >= baseline matched` and
`inventory false positives <= baseline false positives`): **PASS** (28 >= 28,
13 <= 14).

Per-kind recall and type accuracy (inventory): checkbox 0.917/1.00, text
0.636/1.00, number 1.00/1.00, date 1.00/1.00, table field 1.00/1.00. The type
gain is the T052 `table_cell` cue being mapped to `table_field` instead of the
baseline's `unknown`.

Per-page outcomes (inventory): `clean-text` PASS, `numeric-formats` PASS,
`furniture-only` PASS (declared zero fields, nothing invented), `shadow` PASS;
`missing-checkbox` FAIL `missing_fields` (three drawn of four declared);
`duplicate-checkbox` FAIL `duplicate_fields`; `checkbox-row` FAIL
`duplicate_fields` + `extra_fields`; `table` FAIL `duplicate_fields` +
`extra_fields`; `broken-frame` FAIL `missing_fields` + `extra_fields`;
`low-contrast` FAIL `missing_fields`.

Honest findings, not tuned away:

1. Equal counts never pass on wrong geometry. The comparison scores only
   declared pages, matches by exact lattice IoU, and a distance-only match is a
   geometry failure. No page in this corpus passes by count coincidence.
2. Duplicate candidates are reported, not hidden. Adjacent 11 pt checkboxes
   produce two near-duplicate candidates each (IoU 0.83-0.96, below the T055
   0.98 exact-duplicate threshold), so `checkbox-row` fails with five duplicates.
   The detector-side cause lives in T086B's file; the inventory surfaces it.
3. Faint print is invisible to the fixed 128 ink threshold. The `low-contrast`
   page (ink 170) yields zero candidates and three missing fields. That is the
   baseline gap the deferred contrast variant (T264C) must close against the
   frozen thresholds; it is not claimed as fixed.
4. A broken frame is not a field. The open bottom rule leaves three
   underline/whitespace candidates and no single region that matches the declared
   field, so the page fails.
5. A printed table cell is excluded only when its ink passes the 12 % gate. The
   corpus cell is drawn dense enough to pass it; an earlier 11.2 % hatch survived
   the gate as an extra candidate, which is why the corpus now draws a realistic
   printed cell. That is a corpus correction, not a threshold change.
6. Photo quality is measured on the photometric original. The shadow page reports
   `dynamicRange` 101 with `p05=154`, while flat pages report `dynamicRange` 0,
   proving the measurement is taken before any binarisation.

Determinism: two consecutive runs produced byte-identical snapshots; the golden
is committed and the host test fails on any drift.
