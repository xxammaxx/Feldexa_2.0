## 4. Contract coverage

### 4.1 Descriptors, capability kinds, and registry

- `CapabilityKind` has exactly the ten contract values in the contract order:
  `documentImport`, `pageRaster`, `ocr`, `secureStore`, `pdfExport`,
  `delivery`, `lifecycle`, `clock`, `ids`, `diagnostics`.
- `PlatformCapability` exposes one `CapabilityDescriptor get descriptor`. Every
  port implements it.
- `CapabilityDescriptor` carries `kind`, `adapterId`, `version`, `isSimulated`,
  `evidence`, and `supportedFeatures`. It validates at runtime:
  - `adapterId` equals `evidence.adapterId`;
  - `isSimulated` equals `evidence.simulated`, so a simulated capability can
    never be labelled real;
  - `version` is a positive contract version such as `1` or `1.2`;
  - feature tokens are short, non-empty, and contain no whitespace or control
    characters;
  - the feature set is an unmodifiable copy and equality covers every field;
  - `toString()` omits the adapter id and feature tokens.
- `AdapterRegistry` is an interface only. It exposes the ten port getters plus
  `isDevelopmentEnvironment`, `hasSimulatedCapabilities`, and one descriptor per
  capability. The fake registry test returns all ten in `CapabilityKind` order.

### 4.3 Port-local DTOs and enums

`ImportRequest`, `ImportedSource`, `SourceIntegrity`, `RasterRequest`,
`RasterImage`, `RasterFormat`, `OcrRequest`, `OcrBlock`, `OcrLine`, `StoreKind`,
`StoreStatus`, `StoredMeta`, `LoadedDocument`, `LoadedTemplate`,
`CreateDocumentRequest`, `SaveRevisionRequest`, `CreateTemplateRequest`,
`SaveTemplateVersionRequest`, `WriteSignatureRequest`, `DeleteConfirmation`,
`RecoveryStamp`, `ExportRequest`, `ExportResult`, `ExportOptions`,
`DeliveryAction`, `DeliveryOutcome`, and `AppLifecycleSignal` are declared
exactly once and exported by the barrel.

Documented defaults and invariants are enforced at runtime in release mode:

- `ImportRequest.maxBytes` defaults to the 80 MiB cap
  (`83,886,080` bytes; `maxSourceSizeBytes` from core) and can only be lowered.
- `RasterRequest.maxDimensionPx` defaults to `4096`; `scale` is finite and
  positive; `RasterFormat` declares `rgba8888` (4 bytes/pixel) and `gray8`
  (1 byte/pixel).
- `ExportOptions.flatten` and `ExportOptions.embedFonts` default to true.
- SHA-256 values are 64 lowercase hexadecimal characters; ids are lowercase
  UUIDv4; titles are trimmed to 1–200 characters; timestamps are UTC.
- OCR confidence is finite and in the inclusive 0–1 interval.
- A readable `StoredMeta` cannot carry an `unreadableReasonCode`; an unreadable
  entry may name a catalog code such as `SAVE-002`.
- `ImportedSource.pages.length` equals `pageCount`; each failed page is unique
  and inside the source.
- A display name is a name, not a path; a delivery location hint is German
  display text, not a path or URI.
- Collection fields are unmodifiable copies.
- `toString()` on content-bearing DTOs reports lengths/counts, never titles,
  display names, OCR text, or bytes.
