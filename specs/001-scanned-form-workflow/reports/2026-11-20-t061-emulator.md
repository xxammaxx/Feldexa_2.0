## 1. Scope

This run proves the US2 recognition independent test on the real Android
emulator with per-page failure isolation:

- the committed synthetic two-page fixture is imported through the production
  debug composition after page 2's `/MediaBox` is deterministically damaged;
- the import succeeds with exactly one `IMP-006` /
  `unsupportedStructure` page failure and a usable page 1;
- the first production analysis reaches `analysis-ready`;
- page 1 (index 0) is `complete` with real detector suggestions, while page 2
  (index 1) stays `failed`, `unreadable`, and suggestion-free;
- the visible B2 suggestion panel shows page-1 suggestions only;
- navigation to page 2 and back leaves the viewer, page strip, and suggestion
  set usable and unchanged;
- the protected store read-back preserves the page-1 suggestions and the
  page-2 failure.

No system picker is driven by this test; T046/T149 own the picker path. No
production file, fake adapter, fake renderer, fake detector, or fake OCR result
participates.

## 7. Limitations

- Corpus `1.0.0` is `NOT_RUN`: T033/T034 are not assembled. The only claimed
  input is the synthetic `sf-001` fixture.
- This is an `EMULATOR` debug run on the allocated Pixel 7 API 35 AVD. It is
  not a `DEVICE`, release-build, physical-device, or performance claim.
- Per-test runtime socket attribution is `ABSENT`. The committed test source
  contains no network API, and the driver's source check enforces that, but no
  process-level socket inventory isolates test-originated sockets from the
  debug Flutter VM service.
- The unreadable page is persisted with the documented `1 × 1 pt` placeholder,
  so the page-2 failure is evidenced by the compact strip state
  (`Analyse fehlgeschlagen`, `Nicht lesbar`), the German `IMP-006` warning, and
  the absence of suggestions, not by a rendered page-2 document surface.
- The compact page strip is the correct real-device presentation because the
  portrait 1080 × 2400 px / 420 dpi screen is narrower than the documented
  600 dp full-strip breakpoint.
- Suggestion counts/types are runtime detector observations for this synthetic
  fixture; no ground-truth recall claim is made.
- TalkBack, 200% text scale, release signing/packaging, physical-device
  behavior, and corpus scoring were not run.
- Two generic-validator deviations remain, both fixed by T061's authorized-file
  scope: the task package pins the report name `2026-11-20-t061-emulator.md`
  while the generic class rule expects `YYYY-MM-DD-emulator-<slug>.md`, and the
  reports index row in `reports/README.md` is not added because that file is
  outside the authorized scope. The generic validator reports only those two
  findings; its content, artifact, privacy, and status checks pass. The
  coordinator/integrator must add the index row when accepting this report.

   directory, screenshot acknowledgements, and the app-private damaged scratch
   file. `flutter test` removes the debug package after the run.
