## Finding (before the fix)

`AndroidDiagnosticsClient.event()` kept every `String`, `num`, and `bool`
scalar verbatim while its class documentation claimed titles and paths were
"dropped rather than risking a content leak". That inverted the
`contracts/ports.md` §2.9 whitelist (enums, counts, durations, error codes)
and left FR-081's exclusion duty unenforced. The old privacy suite (5/5) was a
characterization of that behavior, not a contract check: it asserted that
`event()` does not throw, with no read access to the buffer.

## Fix

`packages/feldexa_adapters_android/lib/src/android_system_clients.dart`:

- `event()` sanitizes every scalar through a fail-closed `_whitelistedScalar`:
  - `Enum` → its `.name` is retained (compile-time, content-free);
  - non-negative `int` retained (counts and millisecond durations);
  - non-negative `Duration` → `inMilliseconds` retained;
  - `String` retained only when it matches a stable machine grammar — catalog
    code `^[A-Z]{2,6}-[0-9]{3}$` (`SAVE-003`) or dotted lower-camel token
    (`storage.ioError`), at most 64 characters;
  - everything else is dropped: free text, titles, paths, OCR text, field
    values, signature marks, `null`, booleans, doubles, negative numbers,
    nested maps, lists, and byte payloads.
- The class documentation now states the enforced whitelist instead of the
  former claim.
- `@visibleForTesting debugEvents` returns the retained events so the suite can
  assert the exclusion duty (precedent: `AndroidRasterClient.
  debugRememberPageSize`). Retained events are content-free by construction;
  no production log, export, or read accessor was added.
- **Call sites**: no production code calls `diagnostics.event`; only tests do.
  `AndroidDiagnosticsClient` is constructed in
  `apps/feldexa_app/lib/bootstrap/android_platform_runtime.dart`, and the
  registry only exposes the port. No caller needed a change. No new logs or
  exports.

## Regression test (RED → GREEN)

`apps/feldexa_app/test/diagnostics_privacy_test.dart` now asserts the exclusion
duty, not the historical behavior. It smuggles a path, a title, OCR text, a
field value, a signature mark, and a bare lowercase word, plus nested payloads,
`null`, bool, double, and a negative int. It asserts none of that reaches the
retained event under any key (including a flattened-buffer scan), while
`_Probe.retained`, `pageCount: 2`, `Duration(milliseconds: 12)` → `12`,
`SAVE-003`, and `storage.ioError` survive. The ring-buffer cap and `clear()`
are now observed through `debugEvents` instead of only the descriptor.
