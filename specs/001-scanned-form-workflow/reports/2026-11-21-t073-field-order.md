## 3. Behavior delivered in this correction

### 3.1 Pristine vs changed drafts

- `_isPristine` compares the draft against the state captured in `initState`:
  checkbox state for a checkbox field, draft text otherwise (a signature field
  has no editable draft and is pristine).
- `_commitChangedDraft` returns true for pristine drafts without validating,
  converting, or writing. It clears a stale validation error so returning to
  the initial text does not leave a blocking message.
- A changed draft uses the one existing `_commitDraft` path: invalid number,
  date, or over-limit text sets the catalog error and returns false (no move);
  a valid value commits once and then the move/hand-off proceeds.
- Consequences: untouched empty number/date → no `NUM-001`/`DATE-001`; unchanged
  text/checkbox → no `setValue` revision and no T067 undo step; preserved
  `IncompatibleValue` → not rewritten to `TextValue` by pure navigation.

### 3.2 Focus for every target

- Text, multiline, number, and date controls keep their own `autofocus`.
- Checkbox and signature controls are wrapped in `Focus` with an owned
  `FocusNode` and `autofocus: true`; the sheet disposes the node. The
  composition test asserts `hasFocus` on the new target after a swap.

### 3.3 Vanished target recovery

- `FieldValueSheet.onNavigate` is `bool Function(FieldValueNavigation)`;
  `EditorScreen` returns false when the target id or field is gone from the
  latest `_content`.
- On false the sheet resets `_closing` and `_busy`, removing the spinner and
  re-enabling all actions. This complements the correction-1 live-`_content`
  reads, so a concurrent revision change cannot leave the sheet stuck.

1. `field_value_sheet.dart`: `_isPristine` snapshots and `_commitChangedDraft`
   are the whole MEDIUM guard; `_navigate`/`_reorder` only commit through it and
   `_navigate` resets `_closing`/`_busy` when the caller reports no swap.

   `AbsorbPointer` and uses an owned node disposed with the state, so a swap
   creates a fresh autofocus target.

   target and otherwise selects the target and swaps the keyed sheet.

   assert negative behavior (no save, no undo, no error) as well as positive
   focus/move behavior, so a regression to unconditional commits fails.
