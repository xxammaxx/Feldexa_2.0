## 5. What the T020 types guarantee

### 5.1 `DurabilityStatus`

`DurabilityStatus` is a transient sealed union with the states `clean`,
`saving`, `unsaved`, `saved(lastDurableAt)`, `saveFailed(errorCode)`, and
`recoveryFallback(revisionId)`. The payload states validate a UTC timestamp, a
German catalog code such as `SAVE-003`, and a lowercase UUIDv4 revision id.
`isDurable` is true only for `clean` and `saved`, so the type itself cannot
present pending or failed work as durable (FR-046). Status is deliberately not
persisted in a revision.

### 5.2 `RevisionKind`

The enum has exactly the three tokens `autosave`, `explicit`, and `recovery`.
Tests pin them to the T017 `DurablePointer` constants, so there is no second
kind vocabulary.

### 5.3 `RevisionContent`

`RevisionContent` composes the eight `data-model.md` §3.12 payload keys:
`pages`, `suggestions`, `fields`, `fieldOrder`, `values`, `signatures`,
`verification`, and `templateOrigin`. It validates page contiguity, suggestion
ordering and symmetric conflicts, field/page fit, the `fieldOrder` permutation
and `order` positions, value/type compatibility with the
`incompatible_content` warning pairing, signature field/page/asset pairing, and
verification references. Suggestions are sorted into the canonical
page/ordinal order.

The snapshot never contains source bytes. `fromJson` rejects a `source` key
instead of treating it as a benign extension, and `toJson` never emits source,
document metadata, preferences, or the durable head. Unknown same-schema JSON
fields are retained at the content root and every nested persisted object, and
`fromDocument` copies only the snapshot fields. This keeps the payload
independent of `Document` while reusing the T017/T018 value objects.

### 5.4 `Revision`

`Revision` validates UUIDv4 identity and parent, a non-self parent, the kind,
UTC creation time, and a 64-lowercase-hex plaintext SHA-256. It serializes
canonically and preserves same-schema extensions at the revision and content
roots. `toDurablePointer` maps the verified revision to the T017-owned
`DurablePointer` using the shared kind token; callers may invoke it only after
the storage adapter's decrypt-and-hash read-back check.
