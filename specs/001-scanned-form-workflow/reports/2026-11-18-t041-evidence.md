## 7. Limitations

- `NONE` is not a runtime evidence class. No Android runtime, emulator, device,
  SAF picker, channel, Keystore, storage, viewer, OCR, field detection, export,
  or user journey was executed for T041.
- The mapper is a pure Dart translation layer. It does not wire the channel,
  render a dialog, navigate, or persist anything; T040/T042 and later tasks own
  those surfaces.
- The rejection gate proves that the provided flow never calls the creation
  callback on rejection. Real document creation does not exist yet; the flow
  accepts an injected `ImportDocumentWriter`, and persistence behaviour remains
  a later task's evidence.
- FR-007: T039 still reports `import.rejected.unsupportedEncryption` with the
  underlying `IMP-001` code, and the mapper deliberately keeps that observed
  code for callers and diagnostics. Because the catalog has no German string for
  "encrypted with an unsupported mechanism", the UI shows the existing
  truthful `IMP-004` text instead of the password sentence, and
  `passwordProtectionConfirmed` is false. The `IMP-004` recovery guidance
  („Bitte wählen Sie eine PDF-Datei aus.“) is not a perfect fit for an
  encrypted-but-unsupported PDF, so a dedicated catalog code and wording
  remain an owner/T045 follow-up. No catalog or ARB text was changed and no
  replacement German text was invented.
- The raw `IMP-001` password predicate accepts only the typed password kind or
  the canonical `import.rejected.passwordProtected` machine key derived from
  the ports extension. A noncanonical or unknown `IMP-001` message
  deliberately falls back to the truthful `IMP-004` text and never claims
  password protection.
- `isUnrecognized` is mapper-level diagnostic state, not a catalog code. An
  unmapped code and `unclassified()` (a non-`FeldexaException` with no observed
  code) report `true`; every mapped code reports `false`, including
  `import.rejected.unsupportedEncryption` with its observed `IMP-001` code and
  `IMP-004` presentation. `unclassified()` having no observed code but
  reporting `true` is the documented choice: the cause is unknown by
  definition.
- This report supersedes the earlier T041 evidence text that presented
  `import.rejected.unsupportedEncryption` with the `IMP-001` password sentence.
  That presentation was the accepted Review A defect and is corrected by
  `27be54c`; it also supersedes the derived-getter `isUnrecognized` claim,
  corrected by `d3b0a1b`, and the noncanonical password-key predicate and
  incorrect `presentationCode` documentation, corrected by `190d608`. The
  earlier result claims must not be used for acceptance.
- The catalog defines the `{pages}` placeholder but not its grammatical form.

  and invents no German noun. A wording such as „Seite 2“ or „Seiten 2 und 4“
