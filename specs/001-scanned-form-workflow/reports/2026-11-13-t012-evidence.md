## 5. What the shared surface provides

### 5.1 Shared production logic

`packages/feldexa_ui` is a production package consumed by Web and Android; this is
not test-only scaffolding. The plain-data layer is the single source of truth and
is testable without any widget:

- `SimulatedSurface` enumerates exactly the five FR-087 contexts from
  `contracts/error-catalog.de.md` §9: global banner, log prefix, simulated export
  footer, test/report field, and simulated storage notice.
- `SimulatedEvidence` is an immutable descriptor with the exact untranslated
  token `SIMULATED`, the exact `[SIMULATED]` log prefix, the exact
  `evidenceClass: SIMULATED` report field, the German context line for each
  catalogued surface, and a complete German screen-reader label.
- `isAndroidVerification` and `isProductionArtifact` are always `false` for every
  simulated descriptor. `toReportFields()` emits only
  `{'evidenceClass': 'SIMULATED'}`; there is no upgrade path to `EMULATOR` or
  `DEVICE`.
- The banner's accessibility label is exactly the test-asserted contract string:
  `SIMULATED – Entwicklungsansicht mit simulierten Plattformfunktionen. Keine
  Android-Prüfung.`

### 5.2 Widgets

- `SimulatedBanner` is the persistent global Web banner. It renders the exact
  token and the catalogued German context, exposes one complete semantic label,
  has no dismiss/close control, wraps at narrow widths, and remains readable at
  200 % text scale. Its fixed dark palette and amber token exceed 4.5:1 contrast.
- `SimulatedEvidenceLabel` is the compact shared label for logs, reports,
  simulated exports, and simulated storage. It renders the exact marker for the
  surface (including `[SIMULATED]` and `evidenceClass: SIMULATED`) plus the
  German context where the catalog defines one, and wraps at 200 % text scale.
- The barrel `packages/feldexa_ui/lib/feldexa_ui.dart` exports the surface for
  later wiring. T129 remains responsible for mounting the banner and feeding the
  real registry evidence; T012 does not wire the app, logs, or reports.
